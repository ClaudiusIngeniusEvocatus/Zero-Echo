# Zero Echo

A personal journal of working notes at [zeroecho.uk](https://zeroecho.uk) — strategy, scenarios, mission command, contingency, and the cognitive habits in between.

## Local development

Requires Ruby 3.3+ and Bundler.

```bash
bundle install
bundle exec jekyll serve
```

Site runs at `http://localhost:4000`.

## Lineage

Forked with permission from [George Walkley's site](https://github.com/georgewlkly/georgewlkly.github.io), itself derived from [Jekyll Now](https://github.com/barryclark/jekyll-now) by Barry Clark. The Writing Stats widget and core layout structure carry over; identity and content are original to this repository.
